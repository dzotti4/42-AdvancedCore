# Python for Data Science

## Description

A Python piscine in five modules. Every module has its own folder with exercises `ex00`, `ex01`, …

| Module | Topics |
|---|---|
| [0_starting](0_starting) | Python basics: types, formatting, command-line arguments, list comprehensions, lambdas |
| [1_array](1_array) | NumPy arrays and images: slicing, zoom, rotation, color filters |
| [2_datatable](2_datatable) | pandas and matplotlib: loading CSV data and plotting life expectancy, population and income |
| [3_OOP](3_OOP) | Classes, abstract classes, inheritance, diamond inheritance and operator overloading |
| [4_dod](4_dod) | Data-oriented design: statistics with `*args`/`**kwargs`, closures, decorators and dataclasses |

## Instructions

Written for Python 3.10. Modules 1 and 2 need `numpy`, `pandas`, `matplotlib` and `Pillow`.

```bash
pip install numpy pandas matplotlib pillow
cd 3_OOP/ex00 && python3 tester.py
```

All code passes `flake8`, and every function has a docstring.

## What I learned

- Writing clean, documented Python (flake8, type hints, docstrings)
- Working with data in NumPy and pandas
- Object-oriented and data-oriented design in Python
